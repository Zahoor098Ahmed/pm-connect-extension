1. Executive Summary & Core Architecture

PM Connect is an automated developer productivity bridge. It connects local VS Code development environments directly with the centralized Corporate ERP / Project Management system without requiring developers to operate manual timers, write repetitive progress logs, or switch contexts.

⚡ Zero-Friction Tracking

Passively monitors keystrokes, active editor focus, and file edits. When developers pause or switch windows, the timer pauses automatically—guaranteeing 100% accurate, leak-free timesheets.

🌿 Git-Powered Progress

Listens to git commit and push operations. Commits, messages, and touched files are auto-synced to the ERP dashboard, converting file paths into readable modules (e.g. voice.ts → Voice Module).

1 Setting Up the Project in ERP (Admin / Manager)

Before developers begin local tracking, the project must be registered on the ERP portal.

Step 1.1: Log into the ERP Portal

Open your browser and navigate to the corporate CRM/ERP system (e.g. https://crm.tgailab.site or internal local host).

Step 1.2: Register the New Project

  1. Navigate to the Projects tab from the sidebar and click Create New Project.
  2. Fill in the required project metadata:
    • Project Name: Clear human-readable name (e.g. Special Needs Children App).
    • Git Repository URL: The official Git clone URL (e.g. https://github.com/company/angel-talk.git).
    • Assigned Developers: Select developer accounts responsible for the repository.
  3. Save the project. The ERP will issue a unique numeric Project ID (e.g. 15). Note down this ID.

Step 1.3: Obtain Developer API Key

Each developer account possesses a unique Personal Access Token (API Key) stored under User Profile > Developer API Settings (e.g. gt_live_sec_...). Share this key securely with the designated developer.

Security Standard: API Keys authenticate all automated reporting requests. Developers only need to enter their key once; VS Code securely seals it inside the operating system's native secret vault (SecretStorage).

2 Developer Environment Setup (VS Code)

Developers only need to perform this one-time initial configuration inside their editor.

Step 2.1: Install the PM Connect Extension

  1. Launch Visual Studio Code.
  2. Open the Extensions panel by pressing Ctrl + Shift + X (or Cmd + Shift + X on macOS).
  3. Click the three dots (...) in the top-right corner of the Extensions view.
  4. Select Install from VSIX....
  5. Browse and select the provided pm-connect-0.1.0.vsix package.

Step 2.2: Connect the Provider & API Key

  1. Press Ctrl + Shift + P to open the VS Code Command Palette.
  2. Type and execute: PM Connect: Connect Provider.
  3. From the dropdown prompt, select: Custom / Our Website.
  4. When prompted for your API Key, paste your personal access key and hit Enter.
Connection Verification: Look at the bottom-left status bar of VS Code. You should see $(check) PM Connect. This confirms the extension has successfully validated your key against the ERP.

3 Repository-Level Configuration (Team Sharing)

To ensure zero friction for all current and future developers on the repository, create a configuration file at the root of the project.

Create pmconnect.config.json in Workspace Root:

{
  "provider": "custom",
  "projectId": "15",
  "projectName": "Special Needs Children App"
}

Commit this file to GitHub: 

git add pmconnect.config.json
git commit -m "chore: add pmconnect project configuration"
git push origin main
Why this is powerful: Any teammate who clones or pulls this repository will be instantly connected to Project 15 automatically. They will never need to configure URLs or Project IDs manually!

4 Daily Development & Git Workflow

Once configured, developers write code exactly as they normally do. There are zero manual clock-in/clock-out actions.

Activity Developer Action PM Connect Automation
Writing & Editing Code Open files, write logic, save changes. • Silently counts focused coding seconds.
• Auto-pauses if developer walks away (>5 min).
• Appends date-wise sessions to local BACKLOG.md.
Git Commits Run git commit -m "..." in terminal or VS Code Source Control. • Real-time hook intercepts commit SHA & message.
• Records exact files modified.
• Relays telemetry to ERP /commits endpoint.
Git Push Run git push origin main. • Verifies HEAD commit reached remote origin.
• Updates project completion % and milestone trackers on ERP.

Option B: Integrated Push Command

Developers can also trigger git push directly through VS Code:

  1. Press Ctrl + Shift + P.
  2. Select PM Connect: Push & Report Progress.
  3. The extension performs a safe git push, calculates elapsed commits since the last push, updates task completion, and logs the report directly to the ERP.

5 Verification on the ERP Dashboard

When managers and team leads inspect the ERP portal, the following data streams are populated automatically:

📊 Active Coding Hours

Wall-clock time verified against actual keyboard inputs. Idle leakage is strictly zeroed out. Shows daily, weekly, and monthly totals.

📝 Automated Work Digests

Converts raw commit files into human features: e.g. "Aug 25: Worked on Voice Module, Navigation — 'fixed speech recognition latency'".

6. Developer Troubleshooting & FAQ

Common Pitfalls & Quick Solutions:
  • Git Email Mismatch: Ensure your local git user email matches your registered ERP profile email:
    git config user.email "your.email@company.com"
  • Status Bar Shows Warning $(warning): Run PM Connect: Connect Provider and re-enter your API key.
  • Offline Work: If the ERP server is temporarily unreachable, all commits and time heartbeats are safely buffered in local encrypted storage (pending-logs.json) and auto-flushed when connectivity resumes.
